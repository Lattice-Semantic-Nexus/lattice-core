# Lattice Core

<p align="center">
  <img src="assets/lattice-core-logo.png" alt="Lattice Coreate architecture for the AI-native internet."></p>

Lattice Core is the foundational architecture of the Lattice Semantic Nexus.

It defines the architectural layers, structural relationships, and canonical conditions upon which downstream systems are designed to depend.

## Architectural Responsibility

Lattice Core defines:

- Architectural structure
- Layer responsibilities
- Canonical relationships
- Architectural boundaries
- Core architectural primitives

Its responsibility is architectural.

Governance, research, and participation are deliberately separated into distinct ecosystem functions.

## The Lattice Semantic Nexus

The Lattice Semantic Nexus is structured around four distinct but related functions:

- **Lattice Core** — Architecture
- **LSN Foundation** — Governance and Stewardship
- **Lattice Research Institute (LRI)** — Independent Research and Analysis
- **Lattice Community Groups (LCG)** — Participation and Community Engagement

## Architectural Independence

Lattice Core defines the architecture.

Governance protects the architecture through stewardship and process.

Research analyses the architecture independently.

Participation contributes knowledge and perspective without acquiring canonical authority.

This separation preserves a clear distinction between architectural definition and the institutions surrounding it.
